# MyTaalim — الموقع الرسمي

هاد الموقع بسيط: صفحة واحدة (index.html) + صور فمجلد assets/images.
ماشي محتاج build tools ولا npm — تقدر تحطو مباشرة فـ GitHub Pages.

## نشر الموقع فـ GitHub Pages

1. صايب repository جديد فـ GitHub (مثلا: `mytaalim-website`).
2. زيد الملفات ديال هاد المجلد (index.html + assets/) للـ repository.
3. دخل لـ **Settings** ديال الـ repository → **Pages** (فالقائمة الجانبية).
4. تحت "Build and deployment" اختار Source: **Deploy from a branch**.
5. اختار البرانش `main` والمجلد `/ (root)`، دوز Save.
6. سناع دقيقة ولا جوج، الموقع غايبان على:
   `https://<اسم-الحساب-ديالك>.github.io/mytaalim-website/`

## بدل رابط Google Play

الرابط ديال التطبيق موجود فبزاف ديال البلايص فالملف `index.html` —
دوز بحث (Ctrl+F) على `play.google.com/store/apps/details?id=com.qeet.mytaalim`
وبدلو إلا تبدل.
